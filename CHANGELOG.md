# Changes

## OpenPallet 1.2 · 2026-11-10

The first public edition. The OpenPallet file: one JSON file per pallet, every position in one pallet frame,
every orientation and direction in whole degrees counter-clockwise from the top of the drawing, 900 for centred,
for straight down from above and for a gripper without an open side, 999 where nothing is assigned. The fixed
layouts of the same values for PLCs and robots (PLC structures, CSV). The specification and the concept cards in
English, with their Polish translation. The JSON Schema and example files:
[openpallet/schema](https://github.com/openpallet/schema).
